# تنظيف بيانات الدليل قبل التشغيل الفعلي

هذا الإجراء مخصص لمسؤول النظام فقط، ولا يُنفذ أثناء اختبار اللقطات أو مراجعة الدليل. الملف `../../supabase/tips_crm_cleanup_demo_data.sql` يستهدف حساب المندوب التجريبي والخطط التي تبدأ بعلامة **[تجريبي للدليل]** فقط؛ لا يستخدم حذفاً عاماً للخطط أو الحسابات.

| المرحلة | الإجراء المطلوب | شرط الأمان |
|---|---|---|
| 1 | افتح الملف في Supabase SQL Editor ونفّذ استعلام المعاينة فقط. | تأكد أن البريد والدور وعدد الخطط تخص الاختبار فعلاً. |
| 2 | نفّذ كتلة المعاملة كما هي. | النهاية الافتراضية `ROLLBACK`، لذلك لا تُحفظ الحذوفات. |
| 3 | راجع سطر التحقق داخل المعاملة. | يجب أن تكون القيم المتبقية كلها `0`. |
| 4 | إذا تطابقت النتائج مع حساب الاختبار، بدّل `ROLLBACK` الأخير إلى `COMMIT` ثم نفّذ الكتلة مرة واحدة. | لا تغيّر أي شرط بريد أو عنوان خطة إلا بعد مراجعة ثانية. |
| 5 | احتفظ بلقطات الدليل في مستودع المشروع؛ فهي لا تعتمد على بقاء بيانات الاختبار في Supabase. | لا تحذف أصول الدليل أو ملف التنظيف. |

> لا تنفذ `COMMIT` إذا كانت معاينة الحساب أو الخطط تتضمن بيانات موظف أو تشغيل فعلي. في هذه الحالة أوقف الإجراء وراجع مسؤول النظام.
