# دليل التشغيل اليومي — مخطط المحتوى

## الجمهور والنطاق

يستخدم الدليل مدير النظام ومدير المبيعات ومندوب المبيعات والمندوب الطبي داخل Tips CRM بعد حصول كل شخص على بيانات دخوله من الإدارة. لا يغطي تثبيت التطبيق أو النشر أو ربط النطاق أو إعداد قاعدة البيانات.

## المرئيات المعتمدة

| المرئية | المصدر | الغرض |
|---|---|---|
| شاشة الدخول | لقطة واجهة النظام | توضيح بداية الاستخدام لكل الأدوار |
| شاشة إنشاء الخطة الأسبوعية | لقطة هاتف من اختبار النظام | توضيح اختيار الأسبوع والجهات والأيام |
| مسار عمل المدير | مخطط Typst داخل الدليل | توضيح المراجعة والتعديل والاعتماد أو الإعادة |
| مسار يوم المندوب | مخطط Typst داخل الدليل | توضيح الخطة والزيارة والتقرير والمتابعة |

## الفصول

1. دخول آمن وتحديد الواجهة حسب الدور.
2. برنامج اليوم للمندوب والخطة الأسبوعية وزيارات اليوم.
3. توثيق الزيارة والنتيجة والتحصيل أو التفاعل الطبي.
4. إشعارات المندوب والخطة المعتمدة أو المعادة أو المعدلة.
5. اعتماد الخطط للمدير: الفلاتر، الأداء، تعديل الجدول، القرار والتذكير.
6. تقارير المدير: التصدير إلى Excel، التحصيل، والمتابعة الطبية.
7. بطاقات عمل سريعة وحل المشاكل الشائعة.
