# ملاحظات بناء ويب Expo

يستخدم Tips CRM مخرج الويب `single` لإنتاج تطبيق صفحة واحدة (SPA) بملف `index.html` واحد، وهو مناسب لنسخة التجربة الثابتة ولا يحتاج إلى توليد HTML منفصل لكل مسار.

المصدر الرسمي: [Expo — Publish websites](https://docs.expo.dev/guides/publishing-websites/). راجع في 15 أغسطس 2026. توضح الوثائق أن `single` هو المخرج الافتراضي لتطبيق صفحة واحدة، بينما `static` يولد ملفات HTML منفصلة لكل مسار و`server` يخرج ملفات عميل وخادم.
